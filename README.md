# 薬袋式英単語ビューア

『薬袋式英単語暗記法』の各ユニット（1〜232）のQ（英文）とA（訳・解答）の画像を表示するSvelteKitアプリです。

## 教材データの扱い

- 画像はサイトに含めません。初回に、`unit001_Q.jpg`・`unit001_A.jpg`… が入ったフォルダ、または `eitango_unit001-058.zip`〜`eitango_unit175-232.zip` を選択（またはドラッグ＆ドロップ）すると、OPFS（ブラウザ専用の保存領域）に保存します。ZIPはブラウザ内で解凍します。画像やZIPはサーバーへ送信されません。
- 2回目以降はOPFSの画像を使うため、再取り込みは不要です。一部だけ取り込んで、後から「フォルダを取り込み」「ZIP・画像を取り込み」で足すこともできます。
- `unitNNN_Q.jpg` / `unitNNN_A.jpg`（NNNは001〜232）だけを取り込み、それ以外のファイルやmacOSの管理ファイルは無視します。
- サイトデータを削除すると取り込んだ画像も消えるため、再取り込みが必要です。localhost と公開先の保存領域は別です。
- 手元の教材は `local-materials/` に置いてください。ZIP・画像・PDFは `.gitignore` で除外され、ビルド前に Git 追跡対象と `static/` に教材がないか検査します。

## 操作

- ユニット一覧（PCでは左側、スマホでは「Unit ▾」から開く）で各ユニットへ移動できます。番号の直接入力も可能です。
- 表示は Q / A / Q+A（PCでは横並び）から選べます。画像をクリックするとQとAが切り替わります。
- キーボード: `←` `→` でユニット移動、`Space` でQ/A切替、`q` `a` `b` で表示切替。スマホは左右スワイプで移動。
- URLのハッシュ（`#12`、`#12a`）で特定ユニットを直接開けます。最後に見た位置は次回も復元されます。

## ローカルで起動

Node.js 24 以降で実行します。

```sh
npm ci
npm run dev
```

## GitHub Pages へ公開

Settings → Pages → Source で **GitHub Actions** を選び、`main` または `master` へ push すると、型チェック・テスト・教材混入検査の後に `build/` を公開します。

```sh
npm run verify:production
npm run preview
```
