# 薬袋式英単語ビューア

『薬袋式英単語暗記法』の各ユニット（1〜232）を、Q（英文）とA（訳・解答）に分けて表示するSvelteKitアプリです。各面は次の2つの矩形で表示します。

- Q: 問題文（Unit番号・□・番号は除く）と CHECK YOUR VOCABULARY 枠
- A: 訳文（□・番号は除く）と ANSWERS 枠

## 教材データの扱い

- 元データは、手元でスキャンした本のPDFです。初回に、PDFと Unit 1 が載っているページ番号（PDFビューアでの番号、1始まり）を指定します。
- 取り込みはすべてブラウザ内で行います。pdf.js でページを描画し、ページごとにレイアウトを検出して矩形を切り出します（`src/lib/crop-layout.ts`）。
- 切り出した画像とPDFは OPFS（ブラウザ専用の保存領域）に保存します。サーバーへは送信されません。2回目以降は保存済みのデータを使います。
- PDFも保存しているので、「元のページを表示」で切り出し前のページを確認できます。
- レイアウトを検出できなかったUnitは、そのUnitが載っているページの半分を表示し、取り込み後に一覧で知らせます。
- サイトデータを削除すると取り込んだデータも消えるため、再取り込みが必要です。localhost と公開先の保存領域は別です。
- 手元の教材は `local-materials/` に置いてください。PDF・画像・ZIPは `.gitignore` で除外され、ビルド前に Git 追跡対象と `static/` に教材がないか検査します。

## 切り出しの検証

`scripts/detect-crops.py` は検出アルゴリズムの Python 版です。本1冊分の検出結果の統計と、矩形を描き込んだ確認用画像を出力します。TS版と同じ結果になることを確認しています。

```sh
python3 scripts/detect-crops.py <本のPDF> 54 --sheets <確認用画像の出力先>
```

`pymupdf`・`numpy`・`pillow` が必要です。

## 操作

- ユニット一覧（PCでは左側、スマホでは「Unit ▾」から開く）で各ユニットへ移動できます。番号の直接入力も可能です。
- 表示は Q / A / Q+A（PCでは横並び）から選べます。画像をクリックするとQとAが切り替わります。
- キーボード: `←` `→` でユニット移動、`Space` でQ/A切替、`q` `a` `b` で表示切替、`o` で元のページ。スマホは左右スワイプで移動。
- スマホ・タブレット（タッチ操作の端末）では、上部の回転ボタンで画像を90°回転して表示できます。リロードすると元に戻る一時的な設定です。
- URLのハッシュ（`#12`、`#12a`）で特定ユニットを直接開けます。最後に見た位置は次回も復元されます。

## ローカルで起動

Node.js 24 以降で実行します。

```sh
npm ci
npm run dev
```

## GitHub Pages へ公開

Settings → Pages → Source で **GitHub Actions** を選び、`main` または `master` へ push すると、型チェック・テスト・教材混入検査の後に `build/` を公開します。

```sh
npm run verify:production
npm run preview
```
